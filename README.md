# MONTTECH — sitio web

Landing page responsive para MONTTECH, inspirada en la referencia visual compartida: fondo azul oscuro, acentos cian, iluminación tecnológica y tarjetas con bordes luminosos.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño visual y adaptación móvil.
- `script.js`: menú móvil y año automático.

## Probar localmente
Abre `index.html` en tu navegador. No requiere instalación ni dependencias.

## Publicar en Render
1. Sube estos archivos a un repositorio de GitHub.
2. En Render crea un **Static Site** conectado al repositorio.
3. Configura:
   - Build Command: `echo "Sitio estático listo"`
   - Publish Directory: `.`
4. Despliega el sitio.

El sitio usa enlaces de Google Fonts; si no hay conexión, utiliza fuentes de respaldo del sistema.

## Antes de publicar
Verifica el correo, WhatsApp, enlaces sociales y agrega proyectos/testimonios reales cuando estén disponibles.
