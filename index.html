Preguntas frecuentes

Resolvemos algunas dudas antes de comenzar tu próximo proyecto.

¿Qué tipo de proyectos desarrolla MONTTECH?

Desarrollamos sitios web, aplicaciones, soluciones de análisis de datos y herramientas para automatizar procesos, de acuerdo con las necesidades de cada proyecto.

¿Puedo solicitar una solución personalizada?

Sí. Cada idea se revisa para comprender sus objetivos, alcance y necesidades técnicas antes de proponer una solución.

¿Cómo puedo solicitar una cotización?

Cuéntanos qué necesitas mediante el formulario de contacto. El mensaje se preparará para que puedas enviarlo directamente por WhatsApp.

¿Puedo recibir acompañamiento después de la entrega?

Podemos conversar sobre soporte, ajustes y mantenimiento según las características y el alcance acordado para cada proyecto.
